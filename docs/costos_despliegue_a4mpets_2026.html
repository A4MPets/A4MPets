Supuestos de arquitectura

Proyecto actual: Flutter web/PWA, backend Laravel API, base de datos relacional, subida de medios, rutas con GraphHopper y mapas basados en OpenStreetMap.

Produccion minima: HTTPS, dominio propio, base de datos persistente, backups, almacenamiento de imagenes, logs, monitoreo basico y una estrategia para GraphHopper.

Importante: Google Play no aloja backend ni base de datos. Solo permite publicar la app Android. Por eso se presenta como costo adicional de primer ano, no como hosting.

Impuestos: las columnas principales estan antes de IVA/comisiones bancarias. Se incluye una columna mensual con 19% como referencia conservadora.

Decision recomendada

Ruta practica: iniciar con VPS unico recomendado + dominio + Google Play. El primer ano queda alrededor de $ 1.112.453 antes de IVA/comisiones, y permite contar una historia de producto completo: app, backend, mapas, rutas, reportes, comentarios y evidencia tecnica.

Ruta para convocatoria estatal: presentar dos presupuestos: MVP austero en VPS y piloto institucional administrado en Render/Google Cloud. Eso muestra control financiero y capacidad de escalar si hay recursos.

Ruta para empresas: usar Render Pro o Google Cloud si la conversacion exige soporte, logs, auditoria, monitoreo y separacion de responsabilidades.

Advertencias tecnicas: OpenStreetMap permite usar sus datos, pero sus servidores publicos de tiles no tienen SLA y pueden bloquear uso pesado. Para traccion real conviene usar proveedor de tiles o self-host. GraphHopper open source no cobra licencia, pero consume servidor, memoria y mantenimiento de datos OSM.
