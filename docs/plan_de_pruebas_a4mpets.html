2. Resumen del Sistema

A4MPets gestiona usuarios, mascotas, reportes de mascotas perdidas/encontradas, reportes de riesgos, reportes genericos, comentarios, carga de imagenes, mapas y planeación de rutas. El backend expone API JSON en Laravel 12. El frontend esta construido en Flutter con Riverpod y consumo HTTP. La planeación de rutas depende de GraphHopper.

Importante: las pruebas automatizadas existentes en el repositorio se incluyen como parte del plan porque son ejecutables y verificables, pero aqui se registran como pruebas a ejecutar en una fase posterior, no como pruebas ya completadas.

4. Fuera de Alcance

  • Pruebas de penetración profundas o auditoria formal OWASP completa.
  • Validación cartografica exhaustiva de todas las calles del mapa OSM.
  • Pruebas en tiendas de aplicaciones o firma de builds de produccion.
  • Pruebas de accesibilidad certificadas WCAG; se incluye solo una verificación funcional minima.
