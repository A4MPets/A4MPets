Requisitos Funcionales de A4MPets
Definir de forma verificable las capacidades funcionales que el sistema A4MPets debe ofrecer a usuarios y operadores para
gestionar autenticación, mascotas, rutas, reportes, comentarios, viajes, sincronización y navegación asistida.
Contexto
A4MPets es un sistema compuesto por una aplicación Flutter y
un backend Laravel que soporta operación offline-first,
persistencia local, sincronización bidireccional, planeación de
rutas con GraphHopper, reportes georreferenciados,
comentarios unificados y asistencia de viaje con audio.
