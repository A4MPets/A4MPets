# Features

La carpeta `features/` se divide en dos bloques:

- `01_google_play/`: lo que falta para que la app quede publicable y aceptable en Google Play.
- `02_vulnerabilidades/`: hallazgos críticos del código actual que afectan al negocio.
- `03_negocio/`: modelo de negocio, monetizacion y material para inversionistas.

La regla de mantenimiento sigue siendo la misma: cuando cambie algo, se corrige el contenido existente; no se limita a agregar texto nuevo.
