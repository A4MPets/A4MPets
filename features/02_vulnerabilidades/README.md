# Vulnerabilidades

Hallazgos criticos del codigo actual que afectan al negocio. No incluye mitigaciones.

## Documentos

- [Resumen critico](resumen_critico.md)

## Criterio de lectura

Estos hallazgos se escriben como un reviewer agresivo pero factual: se remarca el riesgo, el impacto, la superficie afectada y, cuando el codigo ya cambie, el estado actualizado del hallazgo.
